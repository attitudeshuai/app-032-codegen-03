# 花灯骨架放样与蒙面裁片 · Lantern Frame Lofting

纯前端工具：选灯型 → 填直径/高度/收口 → 出「每根竹篾截多长、弯什么角度」的骨架件表、带缝份的蒙面裁片、以及可 100% 打印的 1:1 放样图与备料单。无后端、无网络请求，断网可用。

## 技术栈

- Vue 3（`<script setup>` 单文件组件）+ TypeScript + Vite 6
- 状态：Vue 自带 `ref / reactive / computed / watch`（无 Pinia / Vuex）
- 额外依赖仅 `vue-router` 4（规格书要求的 6 个路由）
- 手写 CSS；无 UI 组件库、无图表库、无游戏引擎/物理库
- 字体、灯型数据包（`src/data/lantern-types.json`）全部本地打包，无外网 CDN

## 竹篾规格选型核定（承重选型）

解决「细篾下塌、粗篾太沉且上口弯不动、只能凭手感挑」：

- **输入不另起一套**：竖篾/横篾净长取自轮廓母线折线与棱长/周长（geometry、frame 同一公式），弯折处跨度取绑扎点（含补加圈）折线跨，逐层高度与上口收分走同一份灯样参数，蒙面/胶重量取含缝份裁片面积（panels）与工艺参数（`lantern-types.json → bamboo`）。
- **受力账**：蒙面+胶、扎线、LED、竹篾骨架自重逐层归集，g→N（×0.00980665）；逐层合计 ＋ 顶底盖 ＋ 横篾圈自重 **严格等于** 按整灯总重换算（账面全精度，CHK-11）。
- **规格目录 G1~G7**（宽厚 mm 留 1 位）：每跨按简支梁 M=wL²/8、δ=5wL⁴/384EI 核应力与挠度（许用 12N/mm²、挠度 L/150、安全系数 1.35），圆圈再核最小热弯半径 R=25×厚。
- **撑不住当场拦住**，写清拦因是「跨度太长 / 重量太大 / 弯得太急」，并给两条路及代价：① 换粗一档（增重多少克、上口弯弧半径提到多少）；② 多添一道横篾圈（多几米圈篾/扎线、多几个绑扎点）。弯得太急时换粗那条会明确标注此路不通。
- **判定二选一**：全灯按最不利层统一一档（备料简单、加工省事，代价上层更重、上口难弯）／逐层各选一档（省料省重，代价规格多、加工分层）；切换时写明被放弃方案在材料与加工上让出的代价。
- **四处同一份数（CHK-10）**：骨架构件表按选定宽厚/道数重建行；备料统计与材料页按同一份结论出每根截取长度、分规格用料与重量；参数预览把选定截面（线宽=篾厚，1:1）画到各层圈；四处总长/宽厚/道数一致性自检。
- **版次与作废（CHK-12）**：改最大直径或换蒙面即全部重算，并列出四处各自变化（哪几根篾宽厚/道数变、材料页哪几项变、预览哪几层圈变、自检哪条翻了）；未重新确认前构件/备料/预览为待确认数、导出被拦住；确认即旧版灯样与已导出备料单作废，已裁刨篾条退回重定规格。
- 单位：截面 mm（1 位小数），重量 g 与 kg（界面 1 位/3 位小数），力 N。
